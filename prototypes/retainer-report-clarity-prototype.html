Make the payment answer impossible to miss.

Three client-facing report layouts for the core retainer states. The document always answers: what period/cycle is this, how many hours were available, how many were used, and whether anything is due.

1. Payment first The top-right block gives a plain answer before the client reads any ledger math.
2. Same retainer structure Rollover and no-rollover use the same usage table; only the number of rows changes.
3. Work stays scannable Category bands are strong; task rows stay document-like and easy to read in PDFs.
