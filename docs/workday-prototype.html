How to read this prototype

  • Click any task box → opens the task drawer (mocked).
  • Hover any box for ~200 ms → popover lists the individual time entries that built it.
  • Box height = duration on a fixed scale (1 hour = 40px; full column = 8 h workday). Empty space at bottom = capacity remaining.
  • Box color = task category, tinted with the same color-mix pattern as CategoryBadge.
  • Box order within a day = first startedAt on that task ascending.
  • Box content tiers: ≥60 px = title + project + duration · 36–59 px = title + duration · 18–35 px = title only · <18 px = colored sliver (everything in popover).
  • Day total turns red when over 8 h; a thin red bar appears on top of the overflow box.
  • Avatars row filters the grid; weekend toggle reveals Sat / Sun columns.
