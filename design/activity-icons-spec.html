5. Mark-as-Seen Behavior
When the unseen dot gets cleared.
Clears unseen dot
  • Task detail modal opens AND stays open for ≥500ms
  • Fires markTaskViewed mutation
  • Stores Date.now() in taskViewReceipts
Does NOT clear
  • Hovering over the row
  • Viewing a popover preview
  • Opening modal <500ms (accidental click)
  • Any action on the list view (inline edits)
6. Implementation Notes
Key technical decisions for the implementation.
Activity column width: 96px (3 icons — subtasks, comments, description)
Grid: Activity column stays 96px (no change needed — History icon removed, 3 icons fit)
New Convex table: taskViewReceipts — { taskId, orgId, userId, lastViewedAt } indexed by [userId, taskId]
Unseen computation: Extend activityIndicators query — join taskViewReceipts + compare latest activityLog.createdAt against lastViewedAt
Popover component: Use shadcn HoverCard with openDelay={250} closeDelay={100}
Mobile: Icons visible, no hover popovers. Tap on row opens task detail directly.
Audit trail: Task subtitle shows last activity + hover popover shows last 5 events. No separate History icon needed.
