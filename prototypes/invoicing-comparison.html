Summary — what changes vs the approved PRD

Added (6)
  • • "Message to client" block on every invoice
  • • "Last invoiced X days ago" temporal subline (banners + Inbox rows)
  • • State badges on Inbox rows ("within budget", "2.0h over", "cycle close")
  • • "Generate all within-budget reports" batch action in Inbox header
  • • Empty state for the Inbox ("All caught up" with last-invoiced context)
  • • Undo toast on bulk Mark-as-Paid (5s window)
  • • Sidebar tooltip on hover ("3 ready · 2 overdue")
  • • Overdue indicator → alert icon (not a dot)
Refined (1)
  • • Section headers carry counts and money totals inline ("Overdue · 2 invoices · €1,840")
Removed (2)
  • • "Cycle X in progress" info card → folded into Monthly Breakdown header
  • • "Paid this month" metric card → moves to a future Reports surface

Explicitly rejected (kept simple): intent-rich CTA labels, hover-preview on Inbox rows, snooze/skip overflow action, decorative left-border accents on banners. Kept "Generate" / "Generate invoice" everywhere — Notion-minimal copy.

All polish items slot into existing implementation PRs without restructuring the order.
